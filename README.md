# Corretor de Redações

Sistema web de correção de redações desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de auxiliar na avaliação de textos utilizando inteligência artificial.

## Tecnologias utilizadas

- Python
- Flask
- MySQL
- HTML e CSS
- Bootstrap
- API da OpenAI

## Funcionalidades

- Envio de redações para correção.
- Análise textual utilizando inteligência artificial.
- Apresentação de feedback para auxiliar na melhoria da escrita.

## Objetivo

Desenvolver uma aplicação web que auxilie estudantes no processo de aprendizagem da escrita e no aprimoramento de suas redações.
